# Tuning Guide (C#移植版)

## 1. 目的
- 実戦投入前に、探索深さと思考時間の既定値を安全側で決める。

## 2. 変更対象
- `setoption name Depth value <n>`
- `setoption name MoveTime value <ms>`

## 3. 推奨手順
1. `bench 1 10` で環境依存の速度を確認する。
2. `Depth=2/3/4` を比較し、応答時間と着手安定度を確認する。
3. `MoveTime=500/1000/2000` を比較し、タイムアウト余裕を確認する。
4. 最後に `dotnet test` の全通過を再確認する。

## 4. 判定基準
- 優先: 応答不能・時間切れが発生しないこと。
- 次点: 合法手率100%を維持すること。
- 追加: 同一設定で再現性があること。
